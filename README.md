# LGTM
All your GitHub PRs in one keyboard-driven view, with per-file review and "viewed" sync.

    npm install
    npm start            # run
    npm run dist         # build installers for mac/win/linux (run on each OS for best results)

Auth: uses `gh auth token` if the GitHub CLI is logged in, otherwise paste a PAT (stored encrypted).
Press `?` in the app for all shortcuts.
